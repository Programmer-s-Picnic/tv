## Long description
Turn your Android phone into a convenient remote for compatible Android TV and Google TV devices. Pair your TV on your local Wi-Fi network with an on-screen code and enjoy easy access to navigation, Home, Back, volume and media playback controls. Use the phone keyboard to send text to supported fields and find your favorite programs in a simple weekly planner.

Key features:
- Wi-Fi TV discovery and six-character pairing code
- Manual TV IP connection option
- Direction pad, OK, Home, Back, power, volume and playback keys
- Text entry from your smartphone
- Saved schedules for favorite TV programs
- Clean light-blue interface and easy-to-reach controls

Compatibility depends on support for Android TV Remote Protocol v2. This app is not affiliated with Google or TV manufacturers. Certain device and browser-specific features may not be supported. TV program notifications are not yet active.

## Before Play publication
1. Test discovery, PIN pairing and controls on a real Android TV.
2. Review the license, security and maintenance of the third-party protocol dependency.
3. Use a dedicated production upload key with secure backup. Existing GitHub APK workflow uses Flutter's generated signing setup and is NOT a Play release pipeline.
4. Build a signed Android App Bundle (AAB), test through Play Console's internal testing track, and complete Data Safety, content rating, app access, ads declaration and target audience forms accurately.
5. Capture real phone screenshots from an actual build; do not upload prototype mockups as screenshots.
6. Verify release icon, app label, package ID and Play Store assets before submission.
7. Confirm this privacy statement matches the final app's libraries and runtime data handling.

## Important current limitations
The remote library has not been physically verified on the user's TV. Program schedules are stored locally, but system notifications are not yet scheduled. Browser-specific tabs and free-moving pointer control require integration with Champak's TV Browser.
