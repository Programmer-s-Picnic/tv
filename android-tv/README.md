# Champak TV Browser

A lightweight Android / Android TV browser focused on reliable D-pad navigation and a small APK.

## Release 1 features

- Single browser tab
- Always-visible address/search bar
- Google search for non-URL text
- Back, forward, refresh and home
- TV remote / D-pad friendly controls
- Start page with Google, YouTube and Homepage shortcuts
- Bookmarks
- Browsing history
- Address suggestions from bookmarks and history
- Android Download Manager integration
- HTML5 video and fullscreen video
- Zoom in/out/reset
- Desktop/mobile user-agent switch
- Configurable homepage
- Clear history, cookies, cache and site data
- Handles external http/https links
- File chooser support for web uploads
